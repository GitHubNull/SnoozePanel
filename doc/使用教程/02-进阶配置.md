# 02-进阶配置

> 目标：掌握全部配置项，打造符合你家居风格的屏保。
> 前置：已完成 [01-快速上手.md](01-快速上手.md)。

## 完整配置结构

```yaml
snoozepanel:
  enabled: true
  idle_seconds: 60
  exit_cooldown_seconds: 2
  screensaver_entity: input_boolean.ke_ting_ping_bao_kai_guan
  devices:
    mode: whitelist
    list: [dev-abc123, dev-kitchen]
  conditions:
    entity:
      - { entity: binary_sensor.someone_home, state: "on" }
      - { entity: sensor.lux, below: 50 }
    time:
      after: "21:00"
      before: "07:00"
      weekday: [mon, tue, wed, thu, fri, sat, sun]
    sun:
      after_sunset_offset: -30
      before_sunrise_offset: 0
  components:
    clock:
      show: true
      style: chrono
      hour24: true
      seconds: false
      position: center
    calendar:
      show: true
      week_start: 1
      show_week_number: false
      format: "M月D日 dddd"
      position: bottom_center
    lunar:
      show: true
      format: "{lunar_month}{lunar_day} {ganzhi}{zodiac}年"
      position: bottom_center
    weather:
      show: true
      entity: weather.forecast_home
      position: top_right
    texts:
      - content: "室温 {sensor.temp}°C"
        position: top_left
  background:
    type: gradient
    color: "#0b1020"
    gradient:
      from: "#0b1020"
      to: "#1b2a4a"
      angle: 160
    images: ["/local/bg1.jpg", "/local/bg2.jpg"]
    interval_seconds: 30
    dim: 0.45
  display_template: ""
  component_templates:
    clock: ""
    weather: ""
  theme: midnight
```

## 范围控制

### 设备白名单/黑名单

多平板场景下，不同设备显示不同屏保：

```yaml
snoozepanel:
  devices:
    mode: whitelist        # whitelist 仅列表内设备生效 / blacklist 列表内设备不生效
    list: [dev-kitchen]    # 设备 id 列表
```

**如何查设备 id**：
- 方法 1：屏保激活时右下角小字显示当前设备 id
- 方法 2：浏览器访问 HA 时 URL 加 `?snooze_device=xxx`，屏保右下角即显示 `xxx`
- 方法 3：不指定 URL 参数时，首次访问自动生成 `dev-xxxxxx` 并存入浏览器 localStorage

**推荐做法**：平板用 Fully Kiosk 等 App 固定 URL 为 `http://ha:8123/lovelace/home?snooze_device=kitchen`，配置里写 `list: [kitchen]`。

> **关于配置持久化（重要）**：视图级配置写在视图 raw YAML 的 `snoozepanel:` 段，随 Home Assistant 的 lovelace 存储**天然持久化**——重启 HA、刷新浏览器、换 App 都不会丢。
> **每台设备各自的配置记录**（如各平板的差异化表盘/设置）由**后端 custom component** 落盘到 HA `.storage/`，同样跨重启存活（见下方「设备级配置与后端持久化」）。
> `?snooze_device=` 仍是推荐的设备标识做法（固定在 URL 里，稳定可靠）；未指定时自动生成的 `dev-xxxxxx` 只作设备 id 临时标识存浏览器 `localStorage`（不作配置权威存储）。

## 生效条件（AND 组合）

所有配置的条件**同时满足**才会触发屏保；任一条件失效时，即使屏保已激活也会立即退出。

### 实体条件

```yaml
conditions:
  entity:
    - { entity: binary_sensor.someone_home, state: "on" }   # 状态等于
    - { entity: sensor.lux, below: 50 }                      # 数值小于
    - { entity: sensor.temp, above: 18 }                     # 数值大于
```

每条规则三选一：`state`（字符串相等）/ `above`（数值大于）/ `below`（数值小于）。

### 时间条件

```yaml
conditions:
  time:
    after: "21:00"      # 晚 9 点后
    before: "07:00"     # 早 7 点前（与 after 组合表示跨午夜区间）
    weekday: [mon, tue, wed, thu, fri]   # 仅工作日
```

- `after` / `before` 格式 `HH:MM`（24 小时制）
- `after > before` 时表示跨午夜（如 21:00–07:00）
- `weekday` 取值：`mon` `tue` `wed` `thu` `fri` `sat` `sun`

### 日出日落条件

```yaml
conditions:
  sun:
    after_sunset_offset: -30     # 日落后 30 分钟（负值=日落前）
    before_sunrise_offset: 0     # 日出前 0 分钟
```

- 单位：分钟
- 依赖 HA 的 `sun.sun` 实体（默认存在）
- 典型用法：`after_sunset_offset: -30` 表示「日落前 30 分钟到日出」期间允许屏保

## 组件详解

### 时钟（表盘）

```yaml
clock:
  show: true
  style: chrono       # 表盘 id（见下方「内置表盘」）
  hour24: true        # 24 小时制（数字表盘用）
  seconds: false      # 显示秒（秒针/秒位/环形进度）
  position: center    # 位置（见下方「布局」）
```

#### 内置表盘

`style` 填表盘 id。内置 6 款：

| id | 名称 | 类型 | 效果 |
|---|---|---|---|
| `digital` | 数字时钟 | 数字 | 大号时分 + 可选秒与上/下午 |
| `ring` | 数字环 | 数字 | 中央数字 + 外圈环形秒进度（智能手表风） |
| `analog` | 经典模拟 | 模拟 | 简洁圆盘 + 12 刻度 + 时分秒针 |
| `chrono` | 机械计时码表 | 模拟 | 玫瑰金/古铜金金属表圈 + 镂空指针 + 齿轮组（纯 CSS 关键帧匀速传动）+ 日期/星期子表盘（装饰性最强）|
| `minimal` | 极简正装 | 模拟 | 细棒指针 + 罗马时标 + 大留白 |
| `orbit` | 轨道同心圆 | 模拟 | 同心圆环 + 轨道刻度 + 双色调指针 |

示例：

```yaml
clock:
  show: true
  style: chrono       # 机械计时码表
  seconds: true       # 显示秒针
  position: center
```

> 表盘会随 `theme`（midnight/paper）自动配色；`chrono` 按 `theme.key` 使用玫瑰金（深夜）/古铜金（宣纸）金属表圈，两主题下均为奶白表盘。

#### 第三方表盘

「表盘市场」的 **第三方** Tab 会自动列出 `src/ui/faces/thirdparty/<id>/` 下的表盘。当前内置示例：**潜水表**。

| id | 名称 | 类型 | 效果 |
|---|---|---|---|
| `diver` | 潜水表 | 模拟 | 钢壳 + 陶瓷单向旋转表圈 + 夜光时标 + 3 点位日期窗 + 剑形指针/棒棒糖秒针 |

```yaml
clock:
  show: true
  style: diver        # 第三方 · 潜水表
  position: center
```

> 第三方表盘复用同一套 `FaceProps` 与主题系统（`theme.key`），两主题下均自适应。
> 自行开发第三方表盘的目录/Props/主题/动效标准见 [../开发维护/第三方表盘开发指南.md](../开发维护/第三方表盘开发指南.md)。

### 日历

```yaml
calendar:
  show: true
  week_start: 1              # 周起始日：0=周日 1=周一
  show_week_number: false    # 显示周数
  format: "M月D日 dddd"      # 日期格式
  position: bottom_center
```

格式占位符：`YYYY` 年、`M`/`MM` 月、`D`/`DD` 日、`dddd` 星期几（中文）。

### 农历

```yaml
lunar:
  show: true
  format: "{lunar_month}{lunar_day} {ganzhi}{zodiac}年"
  position: bottom_center
```

占位符：
- `{lunar_month}` 农历月份（如「八月」）
- `{lunar_day}` 农历日（如「初一」）
- `{ganzhi}` 干支（如「丙午」）
- `{zodiac}` 生肖（如「马」）
- `{year}` 农历年数字

### 天气

```yaml
weather:
  show: true
  entity: weather.forecast_home   # 你的天气实体
  position: top_right
```

读取实体的 `state`（天气状况）与 `attributes.temperature` / `attributes.humidity`。

### 自定义文本

```yaml
texts:
  - content: "室温 {sensor.temp}°C"
    position: top_left
  - content: "湿度 {sensor.humidity}%"
    position: top_left
```

`{entity_id}` 会被替换为实体的当前状态值。

### 内容组件样式

日历 / 日期 / 农历 / 天气 / 自定义文本均支持 `style` 字段（缺省回退 `basic`），与时钟表盘一样有多种外观，可在编辑器里**点击样式卡片弹窗选择**：

```yaml
calendar: { show: true, style: compact }   # 紧凑月历
weather:  { show: true, style: card }      # 卡片天气
texts:
  - content: "室温 {sensor.temp}°C"
    style: quote                             # 强调文本
```

| 组件 | 内置样式（`style`） | 第三方样式 |
|---|---|---|
| 日历 | `basic` 基础月历 / `compact` 紧凑月历 / `minimal` 极简日历 | `fancy` 彩框月历 |
| 日期 | `basic` 基础日期 / `badge` 胶囊日期 / `stacked` 堆叠日期 | `neon` 霓虹日期 |
| 农历 | `basic` 基础农历 / `pill` 胶囊农历 / `detail` 详版农历 | `seal` 印章农历 |
| 天气 | `basic` 基础天气 / `card` 卡片天气 / `inline` 单行天气 | `minimal` 精简天气 |
| 自定义文本 | `basic` 基础文本 / `badge` 标签文本 / `quote` 强调文本 | `marquee` 滚动文本 |

> 样式弹窗分「全部 / 系统内置 / 第三方」三个 Tab；切换后画布与屏保即时更新。

## 背景

### 纯色

```yaml
background:
  type: color
  color: "#0b1020"
```

### 渐变

```yaml
background:
  type: gradient
  gradient:
    from: "#0b1020"
    to: "#1b2a4a"
    angle: 160        # 渐变角度（度）
```

### 图片轮播

```yaml
background:
  type: image
  images:
    - "/local/bg1.jpg"
    - "/local/bg2.jpg"
  interval_seconds: 30    # 切换间隔
  dim: 0.45               # 暗化遮罩 0–1（0 不暗化，1 全黑）
```

> 图片放 HA 的 `www/` 目录，URL 写 `/local/文件名`。

## 布局：九宫格与绝对坐标

所有组件的 `position` 字段支持两种写法：

**九宫格**（字符串）：
```
top_left    | top_center    | top_right
middle_left | center        | middle_right
bottom_left | bottom_center | bottom_right
```

**绝对坐标**（对象）：
```yaml
position:
  x: 10      # 距左边缘百分比
  y: 20      # 距顶边缘百分比
```

## 主题

```yaml
theme: midnight    # midnight 深夜（深色）/ paper 宣纸（浅色）
```

## 设备级配置与后端持久化

视图 YAML 是「这份视图共用」的配置。若某台平板要**独立覆盖**（如厨房平板用 `minimal` 表盘、客厅用 `chrono`），用设备级配置，落盘到 HA 后端 `.storage/`，断电/重启/清缓存不丢。

### 安装后端 custom component

1. 把仓库的 `custom_components/snoozepanel/` 目录拷贝到 HA 配置目录的 `custom_components/` 下。
2. 在 `configuration.yaml` 中声明该集成（本集成无 UI 配置入口，需靠 YAML 触发加载）：

   ```yaml
   snoozepanel:
   ```

3. 重启 Home Assistant。
4. 后端就绪后，前端通过 WebSocket 读写设备级配置（无需其他配置）。

### 使用

在配置编辑器（GUI）的「显示组件」页底部「设备级覆盖」区，点「**保存为本设备配置**」，即把当前配置存为该设备的独立覆盖。之后该设备启动屏保时，会在视图 YAML 基础上叠加这份覆盖。

- 设备 id 即屏保右下角小字 / `?snooze_device=` 值。
- 后端不可用时（未装 component），屏保仍用视图 YAML 正常工作，仅设备级覆盖不生效（控制台有提示）。
