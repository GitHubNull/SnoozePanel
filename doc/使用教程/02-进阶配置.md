# 02-进阶配置

> 目标：掌握全部配置项，打造符合你家居风格的屏保。

## 完整配置结构

```yaml
snoozepanel:
  enabled: true
  idle_seconds: 60
  exit_cooldown_seconds: 2
  screensaver_entity: input_boolean.ke_ting_ping_bao_kai_guan
  devices:
    mode: whitelist
    list: [dev-abc123, dev-kitchen]
  conditions:
    entity:
      - { entity: binary_sensor.someone_home, state: "on" }
      - { entity: sensor.lux, below: 50 }
    time:
      after: "21:00"
      before: "07:00"
      weekday: [mon, tue, wed, thu, fri, sat, sun]
    sun:
      after_sunset_offset: -30
      before_sunrise_offset: 0
  components:
    clock:
      show: true
      style: digital
      hour24: true
      seconds: false
      position: center
    calendar:
      show: true
      week_start: 1
      show_week_number: false
      format: "M月D日 dddd"
      position: bottom_center
    lunar:
      show: true
      format: "{lunar_month}{lunar_day} {ganzhi}{zodiac}年"
      position: bottom_center
    weather:
      show: true
      entity: weather.forecast_home
      position: top_right
    texts:
      - content: "室温 {sensor.temp}°C"
        position: top_left

    type: gradient
    color: "#0b1020"
    gradient:
      from: "#0b1020"
      to: "#1b2a4a"
      angle: 160

    dim: 0.45
  display_template: ""
  component_templates:
    clock: ""
    weather: ""
  theme: midnight
```

## 范围控制

### 设备白名单/黑名单

多平板场景下，不同设备显示不同屏保：

```yaml
snoozepanel:
  devices:
    mode: whitelist        # whitelist 仅列表内设备生效 / blacklist 列表内设备不生效
    list: [dev-kitchen]    # 设备 id 列表
```

**如何查设备 id**：
- 方法 1：屏保激活时右下角小字显示当前设备 id
- 方法 2：浏览器访问 HA 时 URL 加 `?snooze_device=xxx`，屏保右下角即显示 `xxx`
- 方法 3：不指定 URL 参数时，首次访问自动生成 `dev-xxxxxx` 并存入浏览器 localStorage

**推荐做法**：平板用 Fully Kiosk 等 App 固定 URL 为 `http://ha:8123/lovelace/home?snooze_device=kitchen`，配置里写 `list: [kitchen]`。

> **关于配置持久化（重要）**：视图级配置写在视图 raw YAML 的 `snoozepanel:` 段，随 Home Assistant 的 lovelace 存储**天然持久化**——重启 HA、刷新浏览器、换 App 都不会丢。
> 但**每台设备各自的配置记录**（如各平板的差异化设置）目前尚无后端持久化：`?snooze_device=` 是推荐做法（固定在 URL 里，稳定可靠）；未指定时自动生成的 `dev-xxxxxx` 只存在浏览器 `localStorage`，**清缓存/换设备会变**。设备级配置的后端持久化能力（HA custom component + `.storage/`）已列为 P0 待办，见 `doc/TODO.md`。

## 生效条件（AND 组合）

所有配置的条件**同时满足**才会触发屏保；任一条件失效时，即使屏保已激活也会立即退出。

### 实体条件

```yaml
conditions:
  entity:
    - { entity: binary_sensor.someone_home, state: "on" }   # 状态等于
    - { entity: sensor.lux, below: 50 }                      # 数值小于
    - { entity: sensor.temp, above: 18 }                     # 数值大于
```

每条规则三选一：`state`（字符串相等）/ `above`（数值大于）/ `below`（数值小于）。

### 时间条件

```yaml
conditions:
  time:
    after: "21:00"      # 晚 9 点后
    before: "07:00"     # 早 7 点前（与 after 组合表示跨午夜区间）
    weekday: [mon, tue, wed, thu, fri]   # 仅工作日
```

- `after` / `before` 格式 `HH:MM`（24 小时制）
- `after > before` 时表示跨午夜（如 21:00–07:00）
- `weekday` 取值：`mon` `tue` `wed` `thu` `fri` `sat` `sun`

### 日出日落条件

```yaml
conditions:
  sun:
    after_sunset_offset: -30     # 日落后 30 分钟（负值=日落前）
    before_sunrise_offset: 0     # 日出前 0 分钟
```

- 单位：分钟
- 依赖 HA 的 `sun.sun` 实体（默认存在）
- 典型用法：`after_sunset_offset: -30` 表示「日落前 30 分钟到日出」期间允许屏保

## 组件详解

### 时钟

```yaml
clock:
  show: true
  style: digital      # digital 数字 / analog 模拟表盘
  hour24: true        # 24 小时制
  seconds: false      # 显示秒
  position: center    # 位置（见下方「布局」）
```

### 日历

```yaml
calendar:
  show: true
  week_start: 1              # 周起始日：0=周日 1=周一
  show_week_number: false    # 显示周数
  format: "M月D日 dddd"      # 日期格式
  position: bottom_center
```

格式占位符：`YYYY` 年、`M`/`MM` 月、`D`/`DD` 日、`dddd` 星期几（中文）。

### 农历

```yaml
lunar:
  show: true
  format: "{lunar_month}{lunar_day} {ganzhi}{zodiac}年"
  position: bottom_center
```

占位符：
- `{lunar_month}` 农历月份（如「八月」）
- `{lunar_day}` 农历日（如「初一」）
- `{ganzhi}` 干支（如「丙午」）
- `{zodiac}` 生肖（如「马」）
- `{year}` 农历年数字

### 天气

```yaml
weather:
  show: true
  entity: weather.forecast_home   # 你的天气实体
  position: top_right
```

读取实体的 `state`（天气状况）与 `attributes.temperature` / `attributes.humidity`。

### 自定义文本

```yaml
texts:
  - content: "室温 {sensor.temp}°C"
    position: top_left
  - content: "湿度 {sensor.humidity}%"
    position: top_left
```

`{entity_id}` 会被替换为实体的当前状态值。

## 背景

### 纯色

```yaml
background:
  type: color
  color: "#0b1020"
```

### 渐变

```yaml
background:
  type: gradient
  gradient:
    from: "#0b1020"
    to: "#1b2a4a"
    angle: 160        # 渐变角度（度）
```

### 图片轮播

```yaml
background:
  type: image
  images:
    - "/local/bg1.jpg"
    - "/local/bg2.jpg"
  interval_seconds: 30    # 切换间隔
  dim: 0.45               # 暗化遮罩 0–1（0 不暗化，1 全黑）
```

> 图片放 HA 的 `www/` 目录，URL 写 `/local/文件名`。

## 布局：九宫格与绝对坐标

所有组件的 `position` 字段支持两种写法：

**九宫格**（字符串）：
```
top_left    | top_center    | top_right
middle_left | center        | middle_right
bottom_left | bottom_center | bottom_right
```

**绝对坐标**（对象）：
```yaml
position:
  x: 10      # 距左边缘百分比
  y: 20      # 距顶边缘百分比
```

## 主题

```yaml
theme: midnight    # midnight 深夜（深色）/ paper 宣纸（浅色）
```
