# 03-高级玩法

> 目标：用 `display_template` 动态显隐组件、用 `screensaver_entity` 联动 HA 自动化、用实体占位符做信息看板。
> 前置：已完成 [02-进阶配置.md](02-进阶配置.md)。

## display_template：按实体状态动态显隐

`display_template` 是一段 **JavaScript 表达式**，返回 `true` 显示、`false` 隐藏。可访问三个变量：

- `hass`：完整 hass 对象
- `states`：所有实体状态（`states['sensor.temp'].state`）
- `user`：当前用户（`user.name`、`user.is_admin`）

### 全局显隐

```yaml
snoozepanel:
  display_template: "states['binary_sensor.someone_home'].state === 'on'"
```

整个屏保仅在有人在家时启用。

### 单组件显隐

```yaml
snoozepanel:
  component_templates:
    weather: "parseFloat(states['sensor.temp'].state) > 30"
    lunar: "user.name === 'admin'"
```

- 温度超过 30°C 才显示天气组件
- 仅 admin 用户看到农历

### 优雅降级

模板写错（语法错误/实体不存在）时：
- 该组件**恒显示**（最安全兜底）
- 控制台 `console.warn` 提示一次（不刷屏）

> ⚠️ 模板是 JS 表达式不是 Jinja2。写 `states['x'].state` 而非 `states('x')`。

## screensaver_entity：联动 HA 自动化

配置一个 `input_boolean` 实体作为「屏保状态开关」：

```yaml
snoozepanel:
  screensaver_entity: input_boolean.ke_ting_ping_bao_kai_guan
```

**双向同步**：
- 屏保激活 → 自动 `input_boolean.turn_on`
- 屏保退出 → 自动 `input_boolean.turn_off`
- 外部把该实体 turn_on → 屏保立即激活
- 外部把该实体 turn_off → 屏保立即退出

### 自动化示例：观影模式联动

```yaml
automation:
  - alias: "观影时禁用屏保"
    trigger:
      - platform: state
        entity_id: media_player.tv
        to: "playing"
    action:
      - service: input_boolean.turn_off
        target:
          entity_id: input_boolean.ke_ting_ping_bao_kai_guan
```

### 自动化示例：夜间强制屏保

```yaml
automation:
  - alias: "23 点强制客厅平板进屏保"
    trigger:
      - platform: time
        at: "23:00:00"
    action:
      - service: input_boolean.turn_on
        target:
          entity_id: input_boolean.ke_ting_ping_bao_kai_guan
```

## 实体占位符：信息看板

自定义文本支持 `{entity_id}` 占位符，把屏保变成信息看板：

```yaml
components:
  texts:
    - content: "室温 {sensor.ke_ting_wen_du}°C"
      position: top_left
    - content: "湿度 {sensor.ke_ting_shi_du}%"
      position: top_left
    - content: "PM2.5 {sensor.pm25}"
      position: top_left
    - content: "门外 {sensor.men_wai_ren_ti} 人"
      position: bottom_left
```

占位符在屏保激活时取一次值，之后每秒随 hass 更新自动刷新。

## 组合实战：夜间模式屏保

需求：仅日落后、有人在家、且客厅灯关着时，客厅平板才进屏保；屏保显示时钟+农历+室温。

```yaml
snoozepanel:
  enabled: true
  idle_seconds: 120
  screensaver_entity: input_boolean.ke_ting_ping_bao_kai_guan
  devices:
    mode: whitelist
    list: [kitchen, living-room]
  conditions:
    entity:
      - { entity: binary_sensor.someone_home, state: "on" }
      - { entity: light.ke_ting_deng, state: "off" }
    sun:
      after_sunset_offset: 0
      before_sunrise_offset: 0
  components:
    clock: { show: true, style: analog, position: center }
    lunar: { show: true, format: "{lunar_month}{lunar_day}", position: bottom_center }
    texts:
      - content: "室温 {sensor.ke_ting_wen_du}°C"
        position: top_left
  background:
    type: color
    color: "#000000"
    dim: 0
  theme: midnight
```

## 调试技巧

**看设备 id**：屏保右下角小字。

**看条件求值**：F12 控制台，屏保激活/退出时会打日志。

**模板调试**：把模板表达式直接粘贴到 F12 控制台，手动传入 `hass` 对象测试：

```js
// 在 HA 页面控制台执行
const hass = document.querySelector('home-assistant').hass;
const states = hass.states;
eval("states['sensor.temp'].state > 30")
```
