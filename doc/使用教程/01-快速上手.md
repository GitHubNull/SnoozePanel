# 01-快速上手

> 目标：5 分钟内让你的 HA 平板在闲置后自动进入屏保。
> 读完本文你将学会：安装插件 → 在视图加最小配置 → 看到屏保效果。

## 前置条件

- Home Assistant **2024.7** 或更新版本（v0.11.2 起前端产物改由集成自托管，依赖该版本引入的静态路径 API）
- 有 HA 管理员权限（能改 `configuration.yaml` 与视图 YAML）
- 一块常亮平板（或任何浏览器）挂在 HA 仪表板上

## 第 1 步：安装插件

SnoozePanel 是一个 **HA 集成**（后端 custom component + 前端产物一体分发）。装完集成后，前端产物托管、Lovelace 资源登记、侧边栏「SnoozePanel」配置入口全部**自动完成**，无需手动添加资源。

### 方式 A：HACS 自定义仓库（推荐）

1. 打开 HACS → 右上角 ⋮ → **Custom repositories**
2. 仓库地址填 `https://github.com/GitHubNull/SnoozePanel`，类型选 **Integration**，点添加
3. 在 HACS 集成列表找到 **SnoozePanel**，点安装（HACS 会下载 Release 中的 `snoozepanel.zip` 并解压到 `custom_components/snoozepanel/`）

### 方式 B：手动安装

1. 在本仓库 [Releases](https://github.com/GitHubNull/SnoozePanel/releases) 页下载最新 `snoozepanel.zip`
2. 解压，把得到的 `snoozepanel/` 目录（内含 `__init__.py`、`manifest.json`、`frontend/snoozepanel.js` 等）整个放到 HA 配置目录的 `custom_components/` 下，最终路径为 `custom_components/snoozepanel/`

### 启用集成（两种方式都要做）

1. 在 `configuration.yaml` 中加入一行（本集成无 UI 配置入口，靠 YAML 触发加载）：

   ```yaml
   snoozepanel:
   ```

2. **重启 Home Assistant**
3. 重启后自动就绪：前端产物由集成自托管（`/snoozepanel/snoozepanel.js?v=<版本>`，随 HA 启动页早期加载）、Lovelace 资源自动登记（storage 模式仪表板）、侧边栏出现「SnoozePanel」配置入口

> 验证安装：浏览器打开 HA（已登录状态）按 F12，控制台输入 `customElements.get('snooze-panel')`，返回一个函数即成功；侧边栏应能看到带图标的「SnoozePanel」入口。

> **YAML 模式仪表板用户**：若你的仪表板是 YAML 模式（`mode: yaml`），Lovelace 资源自动登记会跳过，需手动在仪表盘 YAML 的 `resources:` 中加 `- url: /snoozepanel/snoozepanel.js?v=<版本>\n    type: module`。

### 卸载

1. 注释或删除 `configuration.yaml` 中的 `snoozepanel:` 行
2. 删除 `custom_components/snoozepanel/` 目录（HACS 安装的可直接在 HACS 里点「Remove」）
3. 重启 Home Assistant；侧边栏入口与自动登记的资源即随之消失（设备级配置存于 `.storage/snoozepanel`，不删则保留，重装后继续使用）

## 第 2 步：在视图加最小配置

1. 进入你想启用屏保的仪表板视图
2. 右上角 ⋮ → **编辑仪表板** → 再次右上角 ⋮ → **原始配置编辑器**
3. 在**视图配置的最顶部**（与 `views:` 同级）插入：

```yaml
snoozepanel:
  enabled: true
  idle_seconds: 30
  components:
    clock:
      show: true
      style: digital
      position: center
```

4. 找到 `views:` 下你要启用屏保的那个视图，在它的 `cards:` 列表**末尾**追加一张锚点卡片：

```yaml
views:
  - title: 客厅
    cards:
      # ... 你原有的卡片 ...
      - type: custom:snooze-panel
```

> ⚠️ **锚点卡片必须存在**：`type: custom:snooze-panel` 这张卡片自身不显示任何内容，但它是屏保的「开关载体」。没有它，视图的 `snoozepanel:` 配置不会被读取。

5. 点「保存」→ 完成编辑 → **刷新页面**（F5）

## 第 3 步：看到效果

- 在视图上**等待 30 秒不操作**，屏保自动全屏弹出，显示数字时钟
- **轻触屏幕或按任意键**，屏保立即退出，回到原仪表板（无刷新）

## 最小配置说明

| 字段 | 含义 | 默认值 |
|---|---|---|
| `enabled` | 是否启用 | `true` |
| `idle_seconds` | 闲置多少秒触发 | `60` |
| `components.clock.show` | 显示时钟 | `true` |
| `components.clock.style` | `digital` 数字 / `analog` 表盘 | `digital` |
| `components.clock.position` | 九宫格位置 | `center` |

完整配置项见 [02-进阶配置.md](02-进阶配置.md)。

## 常见问题

**Q：等了 30 秒没反应？**
- 检查是否刷新了页面（改完 YAML 必须 F5）
- 检查锚点卡片 `type: custom:snooze-panel` 是否加在了**当前视图**的 cards 末尾
- F12 控制台看有没有红色报错

**Q：屏保弹出来了但马上又退出？**
- 检查 `exit_cooldown_seconds`（默认 2 秒），冷却期内的触摸会被忽略，这是防误触设计，正常现象

**Q：想在多个视图启用？**
- 每个视图都要在 raw YAML 顶部加 `snoozepanel:` 段，且各自 cards 末尾加锚点卡片

**Q：侧边栏「SnoozePanel」入口没有图标？**
- v0.11.2 起前端产物随 HA 启动页早期加载，图标集在侧边栏首渲前注册；先**强制刷新**（Ctrl/Cmd+Shift+R）再确认
- 仍空白：确认 `manifest.json` 版本 ≥ 0.11.2 且已重启 HA；浏览器控制台应能看到 `snoozepanel` 图标集已注册
- 早期版本（< 0.11.2）产物作为 Lovelace 资源加载晚于侧边栏首渲，图标会永久空白，升级到 ≥ 0.11.2 即修复

**Q：配置页（侧边栏 SnoozePanel）编辑器缩成一小块、没铺满？**
- v0.11.2 已修复面板高度链问题并改为全屏自适应布局；确认升级后**强制刷新**页面
- 仍异常：检查浏览器控制台是否有报错，并确认加载的资源 URL 为 `/snoozepanel/snoozepanel.js?v=0.11.2`（或更新版本）

**Q：配置页顶部菜单（基础/外观/条件/设备/高级）点开一闪就关、选不中？**
- v0.11.2 已修复菜单浮层锚点丢失导致的闪退；确认升级后**强制刷新**页面再试
- 仍复现：F12 控制台截图报错并提 Issue（附 HA 版本与浏览器版本）
