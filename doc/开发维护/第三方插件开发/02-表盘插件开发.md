# 02 - 表盘插件开发

> 目标：以最小步骤，写出一款可编译、可安装、可被市场识别的**第三方表盘插件**。
> 前置：[01-插件包格式与SDK.md](01-插件包格式与SDK.md)。

## 一、最小工程结构

拷贝仓库根 `plugin-template/` 即可起步（示例为「像素时钟」）：

```
my-clock/
├── plugin.json          # 清单：id / kind / label / entry / apiVersion / 元数据
└── src/
    └── index.ts         # 入口：定义组件 + 调用 SnoozePanelPluginAPI.registerFace
```

## 二、写组件

表盘组件接收宿主统一的 **`FaceProps`**：

| Prop | 类型 | 含义 |
|---|---|---|
| `now` | `Date` | 当前时间（外层 1s tick 驱动） |
| `seconds` | `boolean` | 是否显示秒 |
| `hour24` | `boolean` | 是否 24 小时制 |
| `theme` | `Theme` | 当前主题（取色 / 字重 / 字体族） |
| `options` | `Record<string, unknown>` | 自定义配置（由属性面板按 schema 写入） |

用宿主 SDK 暴露的 Vue 运行时编写（**不要单独 `import ... from 'vue'` 之后又自行打包 Vue**——
构建会自动 externalize，见第七节）：

```ts
import { computed, defineComponent, h, type PropType } from 'vue';

// 宿主注入的全局 SDK（仅声明用到的面）
declare const SnoozePanelPluginAPI: {
  apiVersion: number;
  registerFace(meta: Record<string, unknown>): void;
};

interface FaceTheme {
  key?: string;
  fontFamily?: string;
  clockWeight?: number | string;
  text?: string;
  textSecondary?: string;
}

const MyFace = defineComponent({
  name: 'MyFace',
  props: {
    now: { type: Object as PropType<Date>, required: true },
    seconds: { type: Boolean, default: false },
    hour24: { type: Boolean, default: true },
    theme: { type: Object as PropType<FaceTheme>, default: () => ({}) },
    options: { type: Object as PropType<Record<string, unknown>>, default: () => ({}) },
  },
  setup(props) {
    const pad = (n: number) => String(n).padStart(2, '0');
    const text = computed(() => `${pad(props.now.getHours())}:${pad(props.now.getMinutes())}`);
    const accent = computed(() =>
      typeof props.options.accent === 'string' ? props.options.accent : '#7fd3ff',
    );
    return () =>
      h('div', {
        class: 'my-face',
        style: {
          fontFamily: props.theme.fontFamily ?? 'ui-monospace, monospace',
          fontWeight: String(props.theme.clockWeight ?? 700),
          color: accent.value,
          fontSize: 'clamp(56px, 15cqw, 200px)',   // 容器查询单位，自适应全屏/预览
          fontVariantNumeric: 'tabular-nums',
        },
      }, text.value);
  },
});
```

> 也可用 `.vue` 单文件组件（构建已启用 `@vitejs/plugin-vue`），入口文件改为 `src/index.vue` 并在
> `src/index.ts` 中引入。

## 三、注册表盘

在脚本末尾调用 `SnoozePanelPluginAPI.registerFace`：

```ts
SnoozePanelPluginAPI.registerFace({
  id: 'my-clock',
  label: '我的时钟',
  kind: 'digital',                 // 'digital' | 'analog'
  author: 'Your Name',
  version: '1.0.0',
  summary: '一句话简介（市场卡片）',
  description: '详细介绍（详情页）',
  usage: '使用指南（详情页）',
  homepage: 'https://example.com',
  license: 'MIT',
  schema: [
    { key: 'accent', label: '强调色', type: 'color', default: '#7fd3ff' },
  ],
  component: MyFace,
});
```

- `id` 必须与插件包目录名一致，并满足 `^[a-z0-9][a-z0-9-]{0,63}$`。
- `component` 为上面的 Vue 组件。
- 其余元数据字段可选，但**建议填全**，市场卡片与详情页会展示。

## 四、声明可配置项（schema）

属性面板按 `schema` 渲染控件并写入 `options`，插件在组件里读取 `props.options[key]`：

```ts
schema: [
  { key: 'accent', label: '强调色', type: 'color', default: '#7fd3ff' },
  { key: 'glow',   label: '霓虹发光', type: 'boolean', default: true },
  { key: 'scale',  label: '缩放', type: 'number', min: 0.5, max: 2, step: 0.1, suffix: '×' },
]
```

支持的 `type`：`color` / `number` / `boolean` / `select` / `text` / `textarea`。
字段完整定义见 [01-插件包格式与SDK.md](01-插件包格式与SDK.md) 第五节。

## 五、主题与自适应

- **按 `theme.key` 取色**（`'midnight' | 'paper'`），不要依赖中文名；
  建议把两套差异集中到一个调色板函数：

  ```ts
  const accent = (key?: string) => (key === 'paper' ? '#1a1a1a' : '#7fd3ff');
  ```

- **尺寸用容器查询单位 + `clamp`**（`cqw` / `cqmin`），一套写法同时适配全屏、编辑器画布与缩略预览。
- **连续动效优先纯 CSS `@keyframes`**，并加 `prefers-reduced-motion: reduce` 静态回退。

## 六、SVG defs 唯一化

同一表盘会同时出现在预览与全屏（多实例），`<defs>` 的 id 必须用 `useId()` 加实例前缀：

```ts
import { useId } from 'vue';
const uid = useId();
const id = (n: string) => `${n}-${uid}`;
```

```ts
h('circle', { fill: `url(#${id('dial')})` })
```

## 七、构建与安装

```bash
# 编译到 ./my-clock/dist/（产物：index.js + plugin.json）
pnpm build:plugin my-clock dist
```

产物即为可安装插件包：

- **目录通道**：把 `my-clock/` 拷到 HA `config/www/snoozepanel/plugins/` 下，市场「安装插件」→「HA 本地目录」填入目录名导入；
- **上传通道**：市场「安装插件」→「文件上传」选择 `index.js`（可附 `plugin.json`）。

安装后进入「表盘市场」→「第三方」Tab，即可看到并选用。安装与信任细节见
[04-安装与信任模型.md](04-安装与信任模型.md)。

## 八、自检清单

- [ ] `plugin.json` 的 `id` 与目录名一致且满足 id 规则，`kind: 'face'`
- [ ] 组件接收 `now / seconds / hour24 / theme / options`
- [ ] 配色按 `theme.key` 分支，midnight / paper 均可读
- [ ] 尺寸用 `cqw/clamp`；动效为纯 CSS 且含 `prefers-reduced-motion` 回退
