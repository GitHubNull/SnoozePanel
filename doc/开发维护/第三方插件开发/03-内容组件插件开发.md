# 03 - 内容组件插件开发

> 目标：写出一款可编译、可安装、可被「样式选择器」识别的**第三方内容组件插件**。
> 前置：[01-插件包格式与SDK.md](01-插件包格式与SDK.md)。

## 一、内容组件模型：类型 / 样式 两级

内容组件（widgets）采用**类型 / 样式**两级模型：

- **类型（type）** 固定为已登记的五种之一：`calendar` / `date` / `lunar` / `weather` / `text`；
- **样式（style）** 是某类型下的一种外观实现，`type + style` 全局唯一标识一个组件。

插件开发即是**为某个已有类型新增一个样式**。例如给「天气」类型加一款 `compact` 样式。

## 二、最小工程结构

拷贝仓库根 `plugin-template/` 起步，改为内容组件：

```
my-weather/
├── plugin.json          # kind: 'widget'，type / style 必填
└── src/
    └── index.ts         # 入口：定义组件 + 调用 SnoozePanelPluginAPI.registerWidget
```

`plugin.json` 示例：

```json
{
  "id": "weather-compact",
  "kind": "widget",
  "type": "weather",
  "style": "compact",
  "label": "紧凑天气",
  "entry": "index.js",
  "apiVersion": 1,
  "author": "Your Name",
  "version": "1.0.0",
  "summary": "一行显示温度与天气状态的紧凑样式。"
}
```

## 三、写组件

内容组件接收宿主统一的 **`WidgetProps`**：

| Prop | 类型 | 含义 |
|---|---|---|
| `now` | `Date` | 当前时间（外层 1s tick 驱动） |
| `hass` | `HassLike` | Home Assistant 状态对象（读实体） |
| `theme` | `Theme` | 当前主题 |
| `options` | `Record<string, unknown>` | 配置（内置字段 + 自定义透传合并） |
| `color` | `string?` | 自定义字体颜色（可选，覆盖主题色） |

```ts
import { computed, defineComponent, h, type PropType } from 'vue';

declare const SnoozePanelPluginAPI: {
  apiVersion: number;
  registerWidget(meta: Record<string, unknown>): void;
};

interface HassLike {
  states?: Record<string, { state?: string; attributes?: Record<string, unknown> }>;
}
interface Theme { key?: string; text?: string; textSecondary?: string; accent?: string }

const WeatherCompact = defineComponent({
  name: 'WeatherCompact',
  props: {
    now: { type: Object as PropType<Date>, required: true },
    hass: { type: Object as PropType<HassLike>, default: () => ({}) },
    theme: { type: Object as PropType<Theme>, default: () => ({}) },
    options: { type: Object as PropType<Record<string, unknown>>, default: () => ({}) },
    color: { type: String, default: '' },
  },
  setup(props) {
    const entityId = computed(() =>
      typeof props.options.entity === 'string' ? props.options.entity : 'weather.home',
    );
    const state = computed(() => {
      const s = props.hass.states?.[entityId.value];
      const temp = s?.attributes?.temperature;
      return s ? `${s.state ?? '--'}  ${temp != null ? `${temp}°C` : ''}`.trim() : '--';
    });
    return () =>
      h('div', {
        style: {
          color: props.color || props.theme.text || 'inherit',
          fontSize: 'clamp(14px, 2cqw, 32px)',
        },
      }, state.value);
  },
});
```

## 四、注册内容组件

```ts
SnoozePanelPluginAPI.registerWidget({
  type: 'weather',                 // 必须是已登记类型
  style: 'compact',                // 类型内唯一
  label: '紧凑天气',
  author: 'Your Name',
  version: '1.0.0',
  summary: '一行显示温度与天气状态的紧凑样式。',
  description: '详细介绍（详情页）',
  usage: '使用指南（详情页）',
  schema: [
    { key: 'entity', label: '天气实体', type: 'text', hint: '如 weather.home' },
  ],
  component: WeatherCompact,
});
```

- `type` 必须是 `calendar` / `date` / `lunar` / `weather` / `text` 之一；
- `style` 在类型内唯一；与内置样式同名时**第三方覆盖内置**。

## 五、主题接入：CSS 变量 + 容器查询单位

宿主会在容器上注入主题 CSS 变量，样式直接取用（两主题自动适配）：

| 变量 | 含义 |
|---|---|
| `--snooze-text` | 主文字色 |
| `--snooze-text-secondary` | 次要文字色 |
| `--snooze-accent` | 强调色（今天高亮 / 标签底色等） |

- 尺寸一律用 `clamp(...)` + 容器查询单位（`cqw` / `cqmin`），一套写法同时适配全屏、画布与缩略预览；
- 需要按主题分支时用 `theme.key`（`'midnight' | 'paper'`），不要依赖中文名；
- `color` prop 存在时应优先于主题色。

> 缩略预览（`WidgetPreview.vue`）会注入带主题底色的容器与样例 `options`、mock `hass`，
> 因此新样式无需额外适配即可在样式选择器中预览。

## 六、属性 schema

与表盘一致（`PropertyField`），写入 `options[key]`。对内容组件而言，
若希望复用类型级内置字段（如 `weather.entity`），**第三方插件请统一使用 `options` 透传**：

```ts
schema: [
  { key: 'entity',        label: '天气实体', type: 'text', hint: '如 weather.home' },
  { key: 'show_humidity', label: '显示湿度', type: 'boolean', default: false },
]
```

字段完整定义见 [01-插件包格式与SDK.md](01-插件包格式与SDK.md) 第五节。

## 七、构建与安装

```bash
# 编译到 ./my-weather/dist/（产物：index.js + plugin.json）
pnpm build:plugin my-weather dist
```

安装：
- **目录通道**：拷到 HA `config/www/snoozepanel/plugins/` 下，市场「安装插件」→「HA 本地目录」导入；
- **上传通道**：市场「安装插件」→「文件上传」选择 `index.js`（可附 `plugin.json`）。

安装后：选中对应内容组件 → 属性区「样式选择卡片」→「第三方」Tab 即可看到新样式。
