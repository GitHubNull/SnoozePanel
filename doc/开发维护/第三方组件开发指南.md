# 第三方内容组件开发指南

> 目标：让任何开发者（或 AI 编程代理）用最小约定，把一款自研的**内容组件样式**接入 SnoozePanel，
> 并被编辑器「样式选择器」自动识别、预览、选用。
> 阅读顺序：先看「目录契约」，再照「内置样式」写，最后跑「验证机制 + 自检清单」。
>
> 说明：本文覆盖**内容组件（widgets）**。表盘（faces）见 [第三方表盘开发指南.md](第三方表盘开发指南.md)。

## 一、核心契约：放入目录即生效

内容组件注册表 `src/ui/widgets/registry.ts` 在**构建时**用 `import.meta.glob` 自动扫描，无需改动任何注册代码。
组件采用「类型 / 样式」两级模型：

| 位置 | 归类 | `source` |
|---|---|---|
| `src/ui/widgets/<type>/<style>/index.vue` | 系统内置样式 | `builtin` |
| `src/ui/widgets/thirdparty/<type>/<style>/index.vue` | 第三方安装样式 | `thirdparty` |

- 第三方样式统一放在 `src/ui/widgets/thirdparty/<type>/<style>/` 下；
- 构建后自动进入「样式选择器」弹窗的 **第三方** Tab；
- `source === 'thirdparty'` 会被弹窗打上「第三方」徽标。

> 也就是说：**新建目录 + 入口组件 → `pnpm build` → 生效**。没有中心化清单要维护。

## 二、目录与文件

```
src/ui/widgets/thirdparty/<type>/<style>/
├── index.vue          # 必需：样式入口组件
├── widget.meta.ts     # 可选：元数据 { label }
├── <外观子组件>.vue    # 可选：拆分子组件
└── <纯逻辑>.ts         # 可选
```

- **`<type>`** 必须为已登记类型之一：`calendar` / `date` / `lunar` / `weather` / `text`；
- **`<style>`** 为该类型内的样式 id（目录名，类型内唯一），例如 `fancy` / `neon` / `marquee`；
- **入口组件必需**：`index.vue`；
- **元数据可选**：`widget.meta.ts`，缺省 `label` 取样式目录名。

### widget.meta.ts 字段

```ts
export default {
  label: '彩框月历',   // 中文显示名（样式选择器卡片用）
};
```

> 类型与样式由目录路径自动解析，无需在元数据里声明。

## 三、统一 Props（WidgetProps）

入口组件通过 `defineProps<WidgetProps>()` 接收运行时数据：

| Prop | 类型 | 含义 |
|---|---|---|
| `now` | `Date` | 当前时间（外层 1s tick 驱动） |
| `hass` | `HassLike` | Home Assistant 状态对象（读实体） |
| `theme` | `Theme` | 当前主题（取色 / 字重 / 字体族） |
| `options` | `Record<string, unknown>` | 该类型配置（内置字段 + 第三方透传合并） |
| `color` | `string?` | 自定义字体颜色（可选，覆盖主题色） |

```vue
<script setup lang="ts">
import { computed } from 'vue';
import type { WidgetProps } from '@/ui/widgets/types';

const props = defineProps<WidgetProps>();
const text = computed(() => /* 用 props.now / props.hass / props.options 计算 */ '');
</script>
```

## 四、主题接入：用 CSS 变量，`cqw/clamp` 自适应

`ScreensaverApp` / `WidgetPreview` 会在容器上注入主题 CSS 变量，样式直接取用（**两主题自动适配**）：

| 变量 | 含义 |
|---|---|
| `--snooze-text` | 主文字色 |
| `--snooze-text-secondary` | 次要文字色 |
| `--snooze-accent` | 强调色（今天高亮 / 标签底色等） |

- 尺寸一律用容器查询单位 + `clamp`，如 `font-size: clamp(16px, 2cqw, 32px)`——
  生产全屏、编辑器画布、样式选择器缩略预览**同一套写法**即可自适应；
- 需要按主题分支时用 `theme.key`（`'midnight' | 'paper'`），不要依赖中文名；
- 强烈建议沿用内置样式的写法，保证预览可读。

> `WidgetPreview.vue` 提供带主题底色的「尺寸容器」，并注入样例 `options` 与 mock `hass`，
> 因此任意新样式无需任何适配即可在样式选择器中预览。

## 五、配置字段与归一化

每种类型在 `src/core/types.ts` 有对应接口，并新增了 `style: string` 字段：

- `CalendarComponent` / `DateComponent` / `LunarComponent` / `WeatherComponent` / `TextComponent` 均含 `style`；
- `src/core/config.ts` 的 `normalizeConfig` 会把缺省 / 非法的 `style` 归一为 `'basic'`（core 不依赖 ui 注册表）；
- 新增配置字段遵循三步走：`types.ts` 声明 + `DEFAULT_CONFIG` 默认值 + `normalizeConfig` 校验。

## 六、验证机制（必须真实验证）

1. **构建**：项目根 `pnpm build` → 产物 `tmp/dist/snoozepanel.js`。
2. **测试**：`pnpm test`（`src/tests/widgets.spec.ts` 断言每类型含 3 内置 + 1 第三方样式、遍历全部样式可挂载渲染）。
3. **真实 UI**（dev 实测台，非脚本伪造）：
   ```bash
   python -m http.server 8765
   # 打开 http://127.0.0.1:8765/dev/
   ```
   - 选中某内容组件 → 属性区「样式选择卡片」→ 进入样式选择器；
   - 切到 **第三方** Tab，确认卡片显示、缩略预览正常；
   - 选中卡片，确认画布与屏保即时更新（回写为该样式）；
   - 分别切 midnight / paper 两主题截图核对。
4. 截图存 `tmp/`，禁止伪造结果。

## 七、自检清单

- [ ] 目录在 `src/ui/widgets/thirdparty/<type>/<style>/`，入口为 `index.vue`
- [ ] `<type>` 属于 calendar / date / lunar / weather / text；`<style>` 类型内唯一
- [ ] `widget.meta.ts` 的 `label` 为中文
- [ ] `defineProps<WidgetProps>()` 接收 `now/hass/theme/options/color`
- [ ] 尺寸用 `cqw/clamp`，颜色用 `--snooze-*` 变量，midnight / paper 均可读
- [ ] 单文件 ≤ 520 行（`eslint max-lines`），必要时拆子组件
- [ ] `pnpm build` / `typecheck` / `lint` / `test` 全绿
- [ ] dev 页真实点击：样式选择器第三方 Tab 可见 → 可选中回写 → 画布/屏保即时更新

## 八、内置样例（`thirdparty/<type>/<style>/`）

仓库内置 5 款第三方样例样式，用于验证「放入目录即生效」契约（未改动 `registry.ts`）：

| 类型 | 第三方样例样式 | 说明 |
|---|---|---|
| calendar | `thirdparty/calendar/fancy/` | 彩框月历 |
| date | `thirdparty/date/neon/` | 霓虹日期 |
| lunar | `thirdparty/lunar/seal/` | 印章农历 |
| weather | `thirdparty/weather/minimal/` | 精简天气 |
| text | `thirdparty/text/marquee/` | 滚动文本 |

> 复刻新样式时，可整体拷贝某个内置样式目录（如 `calendar/basic/`），
> 改目录名、`widget.meta.ts` 与样式即可；放 `thirdparty/` 下则自动归为第三方。
