# 03-验收与自检清单

> 面向 AI 编程代理：交付前逐项核验，全部通过才算完成。
> 本清单按「可验证」原则编写，每一项都有明确的验证方法。

## 一、功能验收

### 1.1 范围控制

- [ ] **视图级门控**：未配置 `snoozepanel:` 段的视图，F12 控制台无 SnoozePanel 相关日志，DOM 中无 `#snoozepanel-root`
- [ ] **设备白名单**：`devices.mode: whitelist` + `list: [dev-xxx]`，非列表设备访问时屏保不激活
- [ ] **设备黑名单**：`devices.mode: blacklist` + `list: [dev-xxx]`，列表内设备访问时屏保不激活
- [ ] **设备 id 显示**：屏保激活时右下角小字显示当前设备 id

### 1.2 生效条件

- [ ] **闲置触发**：`idle_seconds: 5`，停止操作 5 秒后屏保激活
- [ ] **实体条件 state**：`entity: [{entity: binary_sensor.x, state: "on"}]`，实体 off 时屏保不激活
- [ ] **实体条件 above/below**：数值越界时屏保不激活
- [ ] **时间条件跨午夜**：`after: "21:00", before: "07:00"`，白天屏保不激活
- [ ] **weekday 限制**：`weekday: [sat, sun]`，工作日屏保不激活
- [ ] **日出日落偏移**：`after_sunset_offset: -30`，日落前 30 分钟内屏保不激活
- [ ] **条件失效即退出**：屏保激活中，把条件实体改为不满足，屏保 5 秒内自动退出

### 1.3 组件

- [ ] **数字时钟**：显示时分（`seconds: true` 时含秒），24 小时制正确
- [ ] **模拟表盘**：时针/分针/秒针指向正确
- [ ] **日历**：日期正确，`week_start: 1` 时周一在首列
- [ ] **农历**：显示农历月日+干支+生肖，与实际农历一致（可用手机日历对照）
- [ ] **天气**：显示天气状况+温度+湿度，与 HA 实体一致
- [ ] **自定义文本**：`{entity_id}` 占位符被替换为实体当前值
- [ ] **背景纯色**：`type: color` 生效
- [ ] **背景渐变**：`type: gradient` 生效，角度正确
- [ ] **背景图片轮播**：`interval_seconds: 5`，5 秒切换一次
- [ ] **暗化遮罩**：`dim: 0.5` 时背景明显变暗
- [ ] **九宫格位置**：`position: top_right` 组件在右上
- [ ] **绝对坐标**：`position: {x: 10, y: 20}` 组件在距左 10% 距顶 20%
- [ ] **主题**：`theme: midnight` 深色 / `theme: paper` 浅色

### 1.4 配置界面

- [ ] **编辑器打开**：HA 卡片编辑器能打开，无控制台报错
- [ ] **中文界面**：全部 label 为中文
- [ ] **配置回显**：已有配置在编辑器中正确显示
- [ ] **配置保存**：修改后点保存，视图 YAML 中 `snoozepanel:` 段同步更新

### 1.5 交互

- [ ] **触摸退出**：屏保激活后轻触屏幕立即退出
- [ ] **按键退出**：按任意键立即退出
- [ ] **退出冷却**：`exit_cooldown_seconds: 2`，退出后 2 秒内的触摸不触发重新激活
- [ ] **screensaver_entity 激活同步**：屏保激活后该实体自动 turn_on
- [ ] **screensaver_entity 退出同步**：屏保退出后该实体自动 turn_off
- [ ] **screensaver_entity 外部激活**：外部 turn_on 该实体，屏保立即激活
- [ ] **screensaver_entity 外部退出**：屏保激活中外部 turn_off 该实体，屏保立即退出

### 1.6 健壮性

- [ ] **无内存泄漏**：反复激活/退出 20 次，F12 Memory 快照无明显增长
- [ ] **后台标签页暂停**：切到其他标签页 1 分钟，切回后屏保时间显示正确（未多走 1 分钟）
- [ ] **display_template 降级**：故意写错模板 `states['nonexistent'].state`，屏保仍显示，控制台 warn 一次
- [ ] **视图切换清理**：屏保激活中切到其他视图再切回，无重复挂载、无报错
