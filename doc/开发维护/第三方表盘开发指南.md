# 第三方表盘开发指南

> 目标：让任何开发者（或 AI 编程代理）用最小约定，把一款自研表盘接入 SnoozePanel，
> 并被「表盘市场」自动识别、预览、选用。
> 阅读顺序：先看「目录契约」，再照「潜水表示范」写，最后跑「验证机制 + 自检清单」。
>
> 说明：本篇覆盖**源码目录接入（构建期打包进产物）**。若希望以「预编译插件包（app 式）」
> 独立分发、由用户自行安装（无需重新构建宿主），见
> [第三方插件开发/02-表盘插件开发.md](第三方插件开发/02-表盘插件开发.md)。

## 一、核心契约：放入目录即生效

表盘注册表 `src/ui/faces/registry.ts` 在**构建时**用 `import.meta.glob` 自动扫描，无需改动任何注册代码：

| 位置 | 归类 | `source` |
|---|---|---|
| `src/ui/faces/<id>/index.vue` | 系统内置 | `builtin` |
| `src/ui/faces/thirdparty/<id>/index.vue` | 第三方安装 | `thirdparty` |

- 第三方表盘统一放在 `src/ui/faces/thirdparty/<id>/` 下；
- 构建后自动进入「表盘市场」的 **第三方** Tab，并出现在编辑器下拉；
- `source === 'thirdparty'` 会被市场打上「第三方」徽标。

> 也就是说：**新建目录 + 入口组件 → `pnpm build` → 生效**。没有中心化清单要维护。

## 二、目录与文件

```
src/ui/faces/thirdparty/<id>/
├── index.vue          # 必需：入口组件（编排层）
├── face.meta.ts       # 可选：元数据 { id, label, kind }
├── <任意外观子组件>.vue # 可选：如表圈 / 指针 / 表盘
└── palette.ts         # 可选：配色等纯逻辑
```

- **入口组件必需**：`index.vue`；
- **元数据可选**：`face.meta.ts`，缺省时 `id` 取目录名、`label` 取 id、`kind` 取 `'analog'`；
- 目录内可自由拆分子组件 / `.ts` / `.css`，注册表只认 `index.vue` 与 `face.meta.ts`。

### face.meta.ts 字段

```ts
export default {
  id: 'diver',             // 表盘唯一标识（务必与目录名一致）
  label: '潜水表',          // 编辑器 / 表盘市场显示名（中文）
  kind: 'analog' as const, // 'digital' 数字 | 'analog' 模拟
  // —— 下方为市场展示元数据（可选，建议填全）——
  author: 'SnoozePanel 官方',
  version: '1.0.0',
  summary: '单向旋转表圈 + 夜光时标的机械潜水表。',   // 一句话简介（卡片）
  description: '详细介绍……',                      // 详情页
  usage: '使用指南……',                            // 详情页
  homepage: 'https://example.com',
  license: 'MIT',
  // —— 属性面板 schema（可选）——
  schema: [
    { key: 'lume', label: '夜光强度', type: 'number', min: 0, max: 1, step: 0.1, default: 0.6 },
  ],
};
```

| 字段 | 必需 | 说明 |
|---|---|---|
| `id` | 建议 | 唯一标识；缺省取目录名。**与目录名保持一致**，避免引用混乱 |
| `label` | 建议 | 中文显示名 |
| `kind` | 可选 | `'digital'` / `'analog'`；影响市场分组与下拉排序 |
| `author` / `version` / `summary` / `description` / `usage` / `homepage` / `license` | 可选 | 市场卡片与详情页展示的元数据：卡片显示 `author` + `version` 徽标 + `summary`，点击进详情页看 `description` + `usage` |
| `schema` | 可选 | 属性面板字段声明（见下节）；缺省回退时钟类型级默认 schema（`hour24` / `seconds`） |

### 属性 schema（元数据驱动属性面板）

在 `face.meta.ts` 声明 `schema`，编辑器属性面板会据此**动态渲染控件**并写回配置，无需改属性面板代码：

```ts
type PropertyField = {
  key: string;                                    // options[key] 或顶层字段名
  label: string;                                  // 中文标签
  type: 'color' | 'number' | 'boolean' | 'select' | 'text' | 'textarea';
  bind?: 'option' | 'field';                       // 缺省 'option' → component.options[key]
  default?: unknown;                              // 仅占位展示，不写入草稿
  min?: number; max?: number; step?: number; suffix?: string;   // number 约束
  options?: { label: string; value: string | number }[];       // select 候选项
  group?: string;                                 // 分组标题
  hint?: string;                                  // 字段提示
};
```

约定：

- **自定义参数用 `bind: 'option'`（默认）**，写入 `ClockComponent.options[key]`，组件内以 `props.options[key]` 读取；
- **复用时钟顶层字段用 `bind: 'field'`**，如 `hour24` / `seconds`（保持单一数据源）；
- 内置表盘缺省回退 `CLOCK_TYPE_SCHEMA`（`src/ui/faces/registry.ts`）；
- 运行时插件表盘（`registerFace`）的 `schema` 同样生效，见 [插件开发文档](第三方插件开发/01-插件包格式与SDK.md)。

## 三、统一 Props（FaceProps）

入口组件通过 `defineProps<FaceProps>()` 接收运行时数据，全部由外层 1s tick 驱动：

| Prop | 类型 | 含义 |
|---|---|---|
| `now` | `Date` | 当前时间（每秒更新） |
| `seconds` | `boolean` | 是否显示秒（秒针 / 秒位） |
| `hour24` | `boolean` | 是否 24 小时制（数字表盘用，模拟表盘可忽略） |
| `theme` | `Theme` | 当前主题（取色 / 字重 / 字体族） |
| `options` | `Record<string, unknown>` | 自定义参数（由属性面板按 `schema` 写入，缺省 `{}`） |

```vue
<script setup lang="ts">
import type { FaceProps } from '../../types';
const props = defineProps<FaceProps>();
const theme = props.theme; // 注意：模板里直接用 theme.xxx
</script>
```

## 四、主题接入：用 `theme.key`，不要用中文名

`Theme`（`src/ui/themes.ts`）新增了稳定的 `key` 字段：

```ts
export interface Theme {
  key: 'midnight' | 'paper';  // 可靠区分主题
  name: string;               // 中文名（勿用于逻辑判断）
  text: string;
  textSecondary: string;
  accent: string;
  clockWeight: number;
  fontFamily: string;
}
```

约定：

- 按 `theme.key` 派生调色板（如 `palette.ts` 的 `diverPalette(theme.key)`）；
- **两套主题都要保证可读**：午夜（深底）与宣纸（浅底）对比度均达标；
- 建议把差异集中到一处「调色板函数」，入口只做 `const palette = computed(() => makePalette(props.theme.key))`。

## 五、动效约定：优先纯 CSS 关键帧

表盘每 1s 才拿到一次新 `now`，若靠 JS 逐帧动画会明显跳变。**连续机械运动（齿轮、转盘）应交给 CSS `@keyframes`**，走合成层、稳定 60fps：

```css
.gear-spin {
  transform-box: fill-box;   /* SVG 元素以自身包围盒为参照 */
  transform-origin: center;  /* 绕自身中心旋转 */
  animation: gearSpin var(--dur, 60s) linear infinite;
}
@keyframes gearSpin { to { transform: rotate(360deg); } }

/* 无障碍：用户要求减少动态时停转 */
@media (prefers-reduced-motion: reduce) {
  .gear-spin { animation: none; }
}
```

- 传动比按齿数推导，啮合方向相反用 `animation-direction: reverse`；
- 相位对齐用一次性负 `animation-delay`（如 `-${now.getSeconds()}s`），避免每秒重置；
- 指针角度若来自 `clockHands()` 等纯函数，建议加轻量 `transition` 平滑跳变，而非自带 rAF。

## 六、SVG defs 唯一性：用 `useId()` 加前缀

同一表盘会**同时**出现在「市场/编辑器预览」与「全屏」中（多实例）。若 `<defs>` 的 id 写死（如 `id="dial"`），多实例会互相串色。

```ts
import { useId } from 'vue';
const uid = useId();
const id = (n: string) => `${n}-${uid}`;
```

```vue
<defs>
  <radialGradient :id="id('dial')">…</radialGradient>
</defs>
<circle :fill="`url(#${id('dial')})`" />
```

> 命名与引用务必成对使用同一个 `id(...)`，否则会出现「有定义无引用」的空白。

## 七、验证机制（必须真实验证）

1. **构建**：项目根 `pnpm build` → 产物 `tmp/dist/snoozepanel.js`。
2. **测试**：`pnpm test`（`src/tests/faces.spec.ts` 断言第三方表盘被自动注册、`source==='thirdparty'`、可挂载渲染）。
3. **真实 UI**（dev 实测台，非脚本伪造）：
   ```bash
   python -m http.server 8765
   # 打开 http://127.0.0.1:8765/dev/
   ```
   - 「点击进入表盘市场」→ 切到 **第三方** Tab，确认卡片显示、缩略预览正常；
   - 选中卡片，确认回写为当前表盘（属性区显示表盘名）；
   - 「重新应用配置」→「触发屏保」，**分别切 midnight / paper 两主题**截图核对；
   - 有连续动效时，间隔数秒各截一帧，比对确有旋转/位移（非静止）。
4. 截图存 `tmp/`，禁止伪造结果。

- [ ] 元数据（`author`/`version`/`summary`/`description`/`usage`）已填，市场卡片与详情页可见

## 九、潜水表示范（`thirdparty/diver/`）

内置示例，用于验证「放入目录即生效」契约，未改动 `registry.ts`：

| 文件 | 职责 |
|---|---|
| `face.meta.ts` | `{ id: 'diver', label: '潜水表', kind: 'analog' }` |
| `index.vue` | 编排层：`useId()` 命名 defs；按 `theme.key` 取调色板；3 点位日期窗 + 夜光时标 + 分钟轨道 + 表盘文字 |
| `palette.ts` | `diverPalette(key)`：午夜=冷钢+高亮夜光；宣纸=暖钢+收敛夜光 |
| `DiverBezel.vue` | 钢壳（拉丝渐变）+ 滚花边缘 + 陶瓷单向旋转表圈（0-60 分刻度、10–50 数字、12 点夜光定位珠、穹面高光） |
| `DiverHands.vue` | 剑形时分针（夜光内嵌）+ 棒棒糖秒针 + 中心宝石帽；角度取自 `core/clock.ts` 的 `clockHands` |

关键片段（主题接入 + defs 唯一化）：

```vue
<script setup lang="ts">
import { computed, useId } from 'vue';
import type { FaceProps } from '../../types';
import { diverPalette } from './palette';

const props = defineProps<FaceProps>();
const uid = useId();
const id = (n: string) => `${n}-${uid}`;
const palette = computed(() => diverPalette(props.theme.key));
</script>
```

```ts
// palette.ts —— 两主题仅差一套取值
export function diverPalette(key: 'midnight' | 'paper'): DiverPalette {
  return key === 'paper'
    ? { /* 暖钢 + 收敛夜光 */ }
    : { /* 冷钢 + 高亮夜光 */ };
}
```

> 复刻新表盘时，可整体拷贝 `thirdparty/diver/` 目录，改目录名、`face.meta.ts` 与 `palette.ts` 取值即可。
