# 01-环境搭建

> 面向人类开发者：从零搭建 SnoozePanel 本地开发环境。

## 前置软件

| 软件 | 版本要求 | 验证命令 |
|---|---|---|
| Node.js | ≥ 18 | `node -v` |
| pnpm | ≥ 8 | `pnpm -v` |
| Python | ≥ 3.8（跑本地 mock 服务器用） | `python --version` |
| Git | 任意 | `git --version` |

## 克隆与目录约定

```bash
git clone <仓库地址> SnoozePanel
cd SnoozePanel
```

**目录纪律（重要）**：
- `src/` 只放 `.ts` / `.vue` 源码
- `tmp/` 是唯一临时目录：工程文件、依赖、构建产物、dev 页全在这里
- 仓库根的 `node_modules` 是一个 **Junction（目录联接）**，指向 `tmp/node_modules`，不要删除

## 安装依赖

```bash
cd tmp
pnpm install
```

> Windows 用户：若 `pnpm install` 后构建报「找不到 primevue」，检查仓库根 `node_modules` 是否为 Junction。重建方法（PowerShell 管理员）：
> ```powershell
> New-Item -ItemType Junction -Path "仓库根\node_modules" -Target "仓库根\tmp\node_modules"
> ```

## 构建

```bash
cd tmp
pnpm build
```

产物：`tmp/dist/snoozepanel.js`（单文件 IIFE，约 528KB）。

## 跑测试

```bash
cd tmp
pnpm test          # 跑全部单测
pnpm test:watch    # watch 模式
```

测试用 Vitest + jsdom，覆盖 `src/core/` 全部纯函数（农历/条件/设备/模板/配置/时钟）。

## 本地 mock 实测

```bash
cd tmp
python -m http.server 8765
```

浏览器打开 `http://127.0.0.1:8765/dev/`，可：
- 切换主题（深夜/宣纸）、时钟样式（数字/模拟）、背景类型
- 点「立即触发屏保」看效果
- 点「打开配置编辑器」看 PrimeVue 中文编辑器

mock 页在 `tmp/dev/index.html`，内置 mock hass 对象（含 weather/sun/input_boolean 等实体）。

## 真机调试（连接生产 HA）

> ⚠️ 生产环境只读探测，严禁写入。

1. 把 `tmp/dist/snoozepanel.js` 拷贝到 HA 的 `www/` 目录
2. HA 资源里加 `/local/snoozepanel.js`
3. 在专用测试视图（如 `snoozepanel-test`）加配置实测
4. 完毕**删除测试视图**恢复原状

## 常见坑

**Q：`pnpm build` 报「Cannot find module 'primevue/config'」？**
A：仓库根 `node_modules` Junction 被删了，按上方「安装依赖」重建。

**Q：改完代码屏保没变化？**
A：浏览器强刷（Ctrl+F5）清缓存；dev 页产物 URL 带时间戳防缓存，但 HA 资源 URL 不带。

**Q：测试报「Does the file exist」？**
A：`tmp/vitest.config.ts` 里 `server.fs.allow` 必须包含 `src/` 的绝对路径，已配好勿动。
