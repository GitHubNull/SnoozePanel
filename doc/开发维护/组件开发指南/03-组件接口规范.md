# 03-组件接口规范

> 正式 Interface Specification。写内置或第三方内容组件前，本文件是**权威契约**。
> 与 [第三方表盘开发指南](../第三方表盘开发指南.md) 平级：一个管「时钟表盘」，一个管「内容组件」。

## 一、术语

| 术语 | 含义 |
|---|---|
| 内容组件 / widget | 屏保内除时钟外的展示组件（日历/日期/农历/天气/文本） |
| 表盘 / face | 时钟的样式实现，走 `src/ui/faces/`，**不属于**本规范 |
| 类型 / 样式 | 类型（type：calendar/date/lunar/weather/text）下含多款样式（style） |
| 入口组件 | `widgets/<type>/<style>/index.vue`，注册表挂载的根组件 |

## 二、目录契约

| 位置 | 归类 `source` | 必需 |
|---|---|---|
| `src/ui/widgets/<type>/<style>/index.vue` | `builtin` | 是 |
| `src/ui/widgets/thirdparty/<type>/<style>/index.vue` | `thirdparty` | 是 |
| `src/ui/widgets/<type>/<style>/widget.meta.ts` | — | 否 |
| `src/ui/widgets/thirdparty/<type>/<style>/widget.meta.ts` | — | 否 |

- **放入目录即生效**：注册表构建时用 `import.meta.glob` 自动扫描，无需改注册代码；
- **第三方同 type+style 覆盖内置**（`source='thirdparty'`）；
- 目录内可自由拆子组件 / `.ts` / `.css`，注册表只认 `index.vue` 与 `widget.meta.ts`。

## 三、`widget.meta.ts`（样式元数据）

`widget.meta.ts` 默认导出：

```ts
export default {
  label: '倒计时',    // 可选；缺省取目录名（style id）
};
```

| 字段 | 类型 | 必需 | 说明 |
|---|---|---|---|
| `label` | `string` | 否 | 样式中文显示名；缺省取 style id |

注册表解析后得到 `WidgetStyleMeta`：

```ts
interface WidgetStyleMeta {
  type: string;                            // 类型 id（<type> 目录名）
  style: string;                           // 样式 id（<style> 目录名）
  label: string;                           // 中文显示名
  source: 'builtin' | 'thirdparty';        // 来源
  component: Component;                     // 入口组件
}
```

> 供编辑器弹窗使用的纯数据摘要 `WidgetStyleOption` 去掉 `component`（可跨序列化边界传递）。

## 四、`WidgetProps`（统一 Props）

入口组件以 `defineProps<WidgetProps>()` 接收：

```ts
interface WidgetProps {
  now: Date;                               // 当前时间（外层 1s tick 驱动）
  hass: HassLike;                          // HA hass 对象（读实体状态）
  theme: Theme;                            // 当前主题（midnight / paper）
  options: Record<string, unknown>;        // 该组件配置（内置字段 + 第三方自定义合并）
  color?: string;                          // 自定义字体色（可选，缺省用主题色）
}
```

| Prop | 消费方式 | 约定 |
|---|---|---|
| `now` | `computed` 派生日期/时间文本 | **禁止**组件内自建定时器 |
| `hass` | `props.hass.states[entity]` | 实体缺失时优雅隐藏，不抛异常 |
| `theme` | 取色/字重/字体族 | 逻辑分支只用 `theme.key` |
| `options` | 读该组件关心的键 | **只读**，类型收窄 + 缺省回退 |
| `color` | `props.color ?? theme.textSecondary` | 空则回退主题色 |

## 五、配置结构（`options` 的键从哪来）

`options` 由配置层按组件类型合并注入。以 `date` 为例，`components.date` 的字段即 `options` 的键：

```yaml
snoozepanel:
  components:
    date:
      show: true
      format: "YYYY年MM月DD日 dddd"   # → options.format
      layout: { x: 50, y: 20, w: 30 } # 布局由外层管理，不进 options 消费
      color: "#5ea0ff"                # → props.color（独立 Prop）
      options: {}                     # → options 的第三方自定义键（透传）
```

约定：

- **内置字段**（show/format/entity/…）：在 `src/core/types.ts` 声明 + `DEFAULT_CONFIG` 给默认 + `normalizeConfig` 校验；
- **第三方自定义字段**：全部放 `components.<type>.options`，`normalizeConfig` 透传（仅保留 JSON 安全对象）；
- 组件从 `options` 读到的键 = 内置字段与 `options` 子对象的并集。

各内置组件的 `options` 键见 [04-专项指南/](../04-专项指南/)。

## 六、生命周期约定

- 组件**通常无生命周期**（纯展示，数据走 props）；
- 若绑定事件/定时器：`onMounted` 绑定，`onBeforeUnmount` **必须成对解绑**（防内存泄漏）；
- 优先 `computed`，避免 `watch` + `ref` 中间态。

## 七、渲染契约

- 根节点建议单元素，尺寸随内容自适应；
- **字号用 `clamp(最小, Xcqw, 最大)`**（容器查询单位），随屏幕缩放，禁止写死 px；
- 一律 `<style scoped>`，不引全局样式；
- 多实例安全的 SVG `<defs>` id 用 `useId()` 加前缀（命名与引用成对）；
- 持续动效用纯 CSS `@keyframes` + `prefers-reduced-motion` 静态回退。

## 八、性能与 `useId()` 约定

- 同一组件会**同时**出现在画布预览与全屏（多实例）→ SVG id 必须实例唯一；
- 连续动画交 CSS 合成层，不逐帧跑 JS；
- 变换优先 `transform`/`opacity`。

## 九、安装与验证

**内置**：在 `src/ui/widgets/<type>/<style>/` 建目录（含 `index.vue`，可选 `widget.meta.ts`）→ `pnpm build`。

**第三方**：把样式目录整体放进 `src/ui/widgets/thirdparty/<type>/<style>/` → `pnpm build`（第三方同 type+style 覆盖内置）。

验证（必须真实 UI，禁止脚本伪造）：

1. `pnpm test`：`widgets.spec.ts` 自动挂载每个样式组件并断言无控制台报错；
2. `pnpm build` 后 `python -m http.server 8765` → 打开 `http://127.0.0.1:8765/dev/`；
3. 编辑器选中组件 → 打开样式弹窗 → 切换样式 → 屏保实时渲染；
4. **两主题**（midnight / paper）各截图核对；
5. 若有覆盖场景：临时放 `thirdparty/<type>/<style>/` 覆盖目录，确认渲染被替换后移除。

## 十、自检清单

- [ ] 目录在 `src/ui/widgets/<type>/<style>/`（或 `thirdparty/<type>/<style>/`），入口为 `index.vue`
- [ ] `widget.meta.ts` 的 `label` 为中文（可选）
- [ ] `defineProps<WidgetProps>()` 接收 `now/hass/theme/options/color`
- [ ] 不自己 `new Date()` / 不自己 `setInterval`
- [ ] `options` 读取做了类型收窄 + 缺省回退
- [ ] `color` 为空时回退主题色；两主题均对比度达标
- [ ] 字号 `clamp(...cqw...)`；`<style scoped>`
- [ ] 多实例 SVG id 用 `useId()`；动效有 `prefers-reduced-motion` 回退
- [ ] 单文件 ≤ 520 行（`pnpm lint` 通过）
- [ ] `pnpm build` / `typecheck` / `lint` / `test` 全绿
- [ ] dev 页真实点击：分类区可见 → 开启 → 屏保两主题截图核对
