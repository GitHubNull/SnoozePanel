# 天气组件（`weather`）

> 组件 id：`weather` ｜ 来源：内置 ｜ 目录：`src/ui/widgets/weather/<style>/`（默认样式 `basic`）

## 一、功能

读取 HA `weather.*` 实体的状态/温度/湿度并显示（天气状况中文化）。

## 二、配置

```yaml
snoozepanel:
  components:
    weather:
      show: true
      entity: "weather.home"   # weather.* 实体 id
      layout: { x: 50, y: 85, w: 30 }
      color: "#5ea0ff"         # 可选
      options: {}              # 第三方自定义透传
```

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `show` | `boolean` | `false` | 是否显示 |
| `entity` | `string` | `''` | `weather.*` 实体 id |
| `layout` / `color` / `options` | — | — | 同通用契约 |

## 三、`options` 消费键

组件从 `options` 读取 `entity`（与内置字段同名，由配置层合并注入），并据此查 `hass.states`。

## 四、数据来源与渲染

从 `props.hass.states[entity]` 读取：

- `state` → 天气状况（英文 → 中文映射）；
- `attributes.temperature`（number）→ 温度 `26°`；
- `attributes.humidity`（number）→ 湿度 `51%`。

天气状况映射（部分）：`sunny=晴`、`clear-night=晴夜`、`partlycloudy=多云`、`cloudy=阴`、`rainy=雨`、`pouring=暴雨`、`snowy=雪`、`snowy-rainy=雨夹雪`、`fog=雾`、`hail=冰雹`、`lightning=雷电`、`lightning-rainy=雷阵雨`、`windy=大风`、`windy-variant=大风`、`exceptional=异常`。

实现要点：

- **实体不存在时整块不渲染**（`v-if="info"`），不抛异常；
- 数值属性 `typeof === 'number'` 才格式化；
- 缺失温度/湿度时对应 span 不渲染。

## 五、验证

1. `pnpm test`（`widgets.spec.ts` 用 mock hass 断言状态/温度/湿度渲染）；
2. dev 页：把 `entity` 设为 mock 的 `weather.*` → 显示与实体一致；
3. 改实体状态 → 屏保实时更新（hass 推送驱动）。
