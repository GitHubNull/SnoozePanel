# 日历组件（`calendar`）

> 组件 id：`calendar` ｜ 来源：内置 ｜ 目录：`src/ui/widgets/calendar/`

## 一、功能

渲染当月月历网格（6 行 × 7 列），标注今日，可选显示 ISO 周数。

## 二、配置

```yaml
snoozepanel:
  components:
    calendar:
      show: true
      week_start: 1            # 0=周日 1=周一
      show_week_number: false  # 是否显示 ISO 周数
      format: "M月D日 dddd"    # 标题模板
      layout: { x: 15, y: 60, w: 40 }
      color: "#5ea0ff"         # 可选
      options: {}              # 第三方自定义透传
```

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `show` | `boolean` | `false` | 是否显示 |
| `week_start` | `0 \| 1` | `1` | 周起始日（0 周日 / 1 周一） |
| `show_week_number` | `boolean` | `false` | 显示 ISO 周数列 |
| `format` | `string` | `M月D日 dddd` | 标题日期模板 |
| `layout` / `color` / `options` | — | — | 同通用契约 |

## 三、`options` 消费键

组件从 `options` 读取 `week_start` / `show_week_number` / `format`（与内置字段同名，由配置层合并注入）。

## 四、实现要点

- 网格：`buildCalendarGrid(year, month, weekStart)`（恒 6×7，含上下月补位）；
- 表头：`weekdayHeaders(weekStart)`（`week_start:1` 时周一首列）；
- 周数：`isoWeekNumber(row[0].date)`（每行首格所在周）；
- 标题：`formatDate(now, format)`；
- 今日高亮用 `theme.accent` / `--snooze-accent`；
- 非本月单元格 `opacity: 0.3`。

## 五、第三方替换

第三方可在 `src/ui/widgets/thirdparty/calendar/index.vue` 放同 id 目录，整体替换内置日历（`source='thirdparty'`），无需改注册代码。

## 六、验证

1. `pnpm test`（`widgets.spec.ts` 覆盖 `week_start:1` 表头顺序）；
2. dev 页：开启「日历」→ 核对日期正确、`week_start:1` 时周一在首列；
3. 打开 `show_week_number` → 每周行首出现 ISO 周数；
4. 与实际日历（手机/系统）对照。
