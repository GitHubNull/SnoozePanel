# 自定义文本组件（`text`）

> 组件 id：`text` ｜ 来源：内置 ｜ 目录：`src/ui/widgets/text/<style>/`（默认样式 `basic`）

## 一、功能

渲染一段自定义文本，支持 `{entity_id}` 实体占位符替换。

> 与其它组件不同，自定义文本**可以有多条**：配置里是 `components.texts[]` 数组，每条含独立 `content` / `layout` / `color` / `show`。

## 二、配置

```yaml
snoozepanel:
  components:
    texts:
      - content: "室温 {sensor.temp}°C"
        layout: { x: 15, y: 10, w: 30 }
        color: "#5ea0ff"   # 可选
        show: true
        options: {}        # 第三方自定义透传
```

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `content` | `string` | — （必需，否则该条被过滤） | 文本或占位符模板 |
| `show` | `boolean` | `true` | 是否显示（仅显式 `false` 才隐藏） |
| `layout` | `ComponentLayout` | `{x:15,y:10,w:30}` | 位置/尺寸（%） |
| `color` | `string?` | — | 自定义字体色 |
| `options` | `object?` | — | 第三方自定义透传 |

## 三、`options` 消费键

组件从 `options` 读取 `content`（每条文本的 `content` 与 `options` 合并注入）。

## 四、占位符语法

| 写法 | 结果 |
|---|---|
| `{entity_id}` | 用实体当前状态字符串替换 |
| `{entity_id:unit}` | `值 + 单位后缀`，如 `{sensor.temp}°C` 里 `:unit` 为自定义后缀 |
| 实体不存在 | 替换为 `--`（不抛异常） |

> 由 `src/core/text.ts` 的 `renderText` 实现；正则 `\{([a-z_]+\.[a-z0-9_]+)(?::([^{}]*))?\}`。

示例：

```
"室温 {sensor.temperature}°C"        →  室温 23.5°C
"客厅 {light.living_room}"            →  客厅 on
"电压 {sensor.voltage:V}"             →  电压 220V
```

## 五、多条文本：增删与选择

- 编辑器分类区为**每条文本各列一项**（`text_0` / `text_1` …），标签取文本内容（空则「文本 N」）；
- 新增：`addText()` —— push 一条空文本并立即选中；
- 删除：`removeSelectedText()` —— 删除当前选中文本，选中态回退到「时钟」；
- 每条文本有独立显隐开关与 `layout` / `color`。

## 六、验证

1. `pnpm test`（`widgets.spec.ts` 覆盖 `options.content` 渲染与占位符替换）；
2. dev 页：开启一条文本 → 输入含 `{entity_id}` 的模板 → 屏保显示替换后的值；
3. 新增/删除文本条目 → 分类区与屏保同步增删。
