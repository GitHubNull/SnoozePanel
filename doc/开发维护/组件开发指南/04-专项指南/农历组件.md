# 农历组件（`lunar`）

> 组件 id：`lunar` ｜ 来源：内置 ｜ 目录：`src/ui/widgets/lunar/<style>/`（默认样式 `basic`）

## 一、功能

显示农历月日、年干支、生肖，支持格式模板。

## 二、配置

```yaml
snoozepanel:
  components:
    lunar:
      show: true
      format: "{lunar_month}{lunar_day} {ganzhi}{zodiac}"
      layout: { x: 50, y: 70, w: 30 }
      color: "#5ea0ff"   # 可选
      options: {}        # 第三方自定义透传
```

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `show` | `boolean` | `false` | 是否显示 |
| `format` | `string` | `{lunar_month}{lunar_day}` | 农历格式模板 |
| `layout` / `color` / `options` | — | — | 同通用契约 |

## 三、格式占位符（`options.format`）

| 占位符 | 含义 | 示例 |
|---|---|---|
| `{lunar_month}` | 农历月名（含闰月） | `腊月` |
| `{lunar_day}` | 农历日名 | `廿三` |
| `{ganzhi}` | 年干支 | `甲辰` |
| `{zodiac}` | 生肖 | `龙` |
| `{year}` | 农历年数字 | `2024` |

> 由 `src/core/lunar.ts` 的 `formatLunar` 替换；占位符缺失/越界时返回空串，组件 `v-if` 隐藏。

## 四、实现要点

- 换算：`solarToLunar(date)` 自包含 1900–2100 位表，**零第三方依赖**；
- 渲染：`formatLunar(props.now, format)` 派生（`computed`）；
- 无结果（`formatLunar` 返回空串）时整块不渲染；
- 字号 `clamp(16px, 2.2cqw, 32px)`，字距 `letter-spacing: 0.05em`。

## 五、验证

1. `pnpm test`（`lunar.spec.ts` 覆盖换算与格式化；`widgets.spec.ts` 覆盖挂载）；
2. dev 页：开启「农历」→ 显示农历月日；
3. 用手机日历对照农历日期/干支/生肖一致。
