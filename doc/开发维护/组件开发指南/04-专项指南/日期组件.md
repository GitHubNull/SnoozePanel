# 日期组件（`date`）

> 组件 id：`date` ｜ 来源：内置 ｜ 目录：`src/ui/widgets/date/<style>/`（默认样式 `basic`）

## 一、功能

按 **ISO 8601 风格占位符**模板渲染当前日期，支持自定义格式。

## 二、配置

```yaml
snoozepanel:
  components:
    date:
      show: true
      format: "YYYY年MM月DD日 dddd"
      layout: { x: 50, y: 20, w: 30 }
      color: "#5ea0ff"     # 可选
      options: {}          # 第三方自定义透传
```

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `show` | `boolean` | `false` | 是否显示 |
| `format` | `string` | `YYYY年MM月DD日 dddd` | 日期格式模板 |
| `layout` | `ComponentLayout` | `{x:50,y:20,w:30}` | 位置/尺寸（%） |
| `color` | `string?` | — | 自定义字体色 |
| `options` | `object?` | — | 第三方自定义透传 |

## 三、格式占位符（`options.format`）

| 占位符 | 含义 | 示例 |
|---|---|---|
| `YYYY` | 四位年 | `2026` |
| `YY` | 两位年 | `26` |
| `MM` | 两位月 | `09` |
| `M` | 月（无前导零） | `9` |
| `DD` | 两位日 | `11` |
| `D` | 日（无前导零） | `11` |
| `dddd` | 星期全称 | `周五` |
| `ddd` | 星期简称 | `五` |

> 替换顺序**先长后短**（`YYYY` 优先于 `YY`，`MM` 优先于 `M`），由 `src/core/clock.ts` 的 `formatDate` 保证。可实现纯文本 + 占位符任意组合，如 `"YYYY/MM/DD"`、`"M月D日 dddd"`、`"YY-MM-DD"`。

## 四、实现要点

- 入口 `index.vue`：`format` 从 `options` 读，缺省回退 `YYYY年MM月DD日 dddd`；
- 文本由 `formatDate(props.now, format)` 派生（`computed`）；
- 字体色：`:style="{ color: props.color }"`，为空时用主题色；
- 字号 `clamp(16px, 2.2cqw, 32px)`。

## 五、验证

1. `pnpm test`（`widgets.spec.ts` 覆盖 `date` 的 `options.format` 渲染与缺省模板）；
2. dev 页：编辑器开启「日期」→ 修改格式模板 → 屏保实时呈现；
3. 分别用 `"YYYY-MM-DD dddd"`、`"M月D日 ddd"`、`"YY/MM/DD"` 核对结果。
