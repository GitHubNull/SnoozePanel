# 03-主题与样式约定

> 目标：让你的组件在「午夜 / 宣纸」两套主题下都好看、可读、随屏幕缩放。

## 一、两套主题

主题定义在 [themes.ts](../../../../src/ui/themes.ts)，仅两套：

| 主题 | `key` | 底色 | 文字 |
|---|---|---|---|
| 深夜 | `midnight` | 深色 | 浅色文字 |
| 宣纸 | `paper` | 浅色 | 深色文字 |

```ts
export interface Theme {
  key: 'midnight' | 'paper';  // 可靠区分主题，勿用 name
  name: string;               // 中文名（勿用于逻辑判断）
  text: string;               // 主文字色
  textSecondary: string;      // 次要文字色
  accent: string;             // 强调色
  clockWeight: number;        // 时钟字重
  fontFamily: string;         // 字体族
}
```

## 二、用 `theme.key` 分支，不要用 `name`

组件通过 `props.theme` 拿到当前主题：

```ts
import { computed } from 'vue';
import type { WidgetProps } from '../types';
const props = defineProps<WidgetProps>();
const isPaper = computed(() => props.theme.key === 'paper');
```

约定：

- **逻辑判断只用 `theme.key`**；`theme.name` 是中文显示名，可能随文案调整；
- 两套主题都要保证**对比度达标**，切换主题截图核对。

## 三、两种取色方式

### 方式 A：取主题色（推荐，自动适配）

```vue
<template>
  <div class="x" :style="{ color: props.color ?? props.theme.textSecondary }">…</div>
</template>
```

- `props.color` 是用户在属性面板选的自定义色，为空时回退主题色；
- 次要信息用 `theme.textSecondary`，强调信息用 `theme.accent`。

### 方式 B：内联注入 CSS 变量

屏保根组件会注入 `--snooze-accent` 等变量，可直接在 scoped 样式里引用：

```css
.today { color: var(--snooze-accent, #5ea0ff); }
```

> 缺省值（`#5ea0ff`）用于脱离屏保单独渲染（如预览/测试）时不崩。

## 四、相对字号：用容器查询单位 `cqw`

屏保会整体缩放适配不同屏幕尺寸，**禁止写死 px 字号**。用 `clamp(最小, Xcqw, 最大)`：

```css
.title  { font-size: clamp(16px, 2.2cqw, 32px); }
.detail { font-size: clamp(12px, 1.6cqw, 20px); }
```

- `Xcqw` = 容器宽度的百分比，随屏幕自适应；
- 先写 `min`（小屏可读下限）与 `max`（大屏不失控上限），再调中间的 `cqw`。

## 五、样式隔离

- 一律用 `<style scoped>`，避免污染其它组件；
- 需要复用变量时用 `:deep()` 谨慎穿透，或改用内联 `:style`；
- **不引入全局样式**，组件自带全部样式。

## 六、可读性清单

- [ ] 用 `theme.key` 分支，未硬编码「深夜/宣纸」中文字符串做判断
- [ ] 文字色取 `theme.text` / `textSecondary` / `accent` 或 `props.color`
- [ ] 字号为 `clamp(...cqw...)`，随屏幕缩放
- [ ] `midnight` / `paper` 两套主题下对比度达标（截图核对）
- [ ] 自定义色（`props.color`）为空时回退主题色，不出现「无颜色」
