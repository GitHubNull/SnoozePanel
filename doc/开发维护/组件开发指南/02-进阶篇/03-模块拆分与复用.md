# 03-模块拆分与复用

> 目标：组件写到复杂时，如何按工程红线拆分，保持单文件 ≤ 520 行。

## 一、红线：单文件 ≤ 520 行

`eslint.config.js` 的 `max-lines` 强制手写源码单文件 **≤ 520 行**，`pnpm lint` 会拦截，**禁止用 `eslint-disable` 绕过**。超限必须拆分。

## 二、拆分原则：逻辑 / 视图 / 数据

| 层 | 放哪 | 说明 |
|---|---|---|
| 纯逻辑 | 目录内 `*.ts` 或提到 `src/core/` | 无副作用、可单测 |
| 子视图 | 目录内子组件 `*.vue` | 只负责渲染片段 |
| 入口编排 | `index.vue` | 组合数据 + 子视图，保持薄 |

> **优先把可测纯逻辑放进 `src/core/`**（`src/core/` 禁止 import 任何 DOM API）。仅本组件专用的逻辑放目录内 `*.ts`。

## 三、示例：拆一个复杂组件

假设要写「闹钟倒计时」组件，含圆环进度 + 数字 + 标签：

```
src/ui/widgets/countdown/
├── index.vue        # 入口：读 options/now，编排子视图
├── widget.meta.ts   # { label: '倒计时' }
├── Ring.vue         # SVG 圆环进度（纯视图）
├── useCountdown.ts  # 倒计时计算（本组件专用逻辑）
└── palette.ts       # 两主题配色（可选）
```

入口保持薄：

```vue
<script setup lang="ts">
import { computed, useId } from 'vue';
import type { WidgetProps } from '../types';
import Ring from './Ring.vue';
import { useCountdown } from './useCountdown';

const props = defineProps<WidgetProps>();
const uid = useId();
const { remaining, progress } = useCountdown(props);  // 逻辑下沉
</script>

<template>
  <div class="countdown">
    <Ring :id="uid" :progress="progress" :color="props.color ?? props.theme.accent" />
    <span class="num">{{ remaining }}</span>
  </div>
</template>
```

要点：

- **入口只做编排**，把计算下沉到 `useXxx` / `src/core`；
- **子组件用 props 传入**，不直接读全局；
- 多实例安全的 id 用 `useId()` 在入口生成后下发。

## 四、复用已有 `src/core/` 纯函数

很多能力已在 `src/core/` 实现，**优先复用**而非重写：

| 需求 | 复用 | 文件 |
|---|---|---|
| 日期格式化（ISO 占位符） | `formatDate` | `src/core/clock.ts` |
| 月历网格 / 周表头 / ISO 周数 | `buildCalendarGrid` / `weekdayHeaders` / `isoWeekNumber` | `src/core/clock.ts` |
| 农历换算 / 格式化 | `solarToLunar` / `formatLunar` | `src/core/lunar.ts` |
| 实体占位符替换 | `renderText` | `src/core/text.ts` |
| 读实体状态 / 数值 | `getState` / `getNumericState` | `src/core/hass.ts` |

> 在 `src/core/` 加新纯函数时，**必须**补 `src/tests/*.spec.ts` 单测。

## 五、复用其它组件？先想清楚

- **可提取到 `src/core/` 的逻辑** → 提取（可测、无 DOM）；
- **纯视觉片段** → 子组件，放本组件目录内（避免跨组件耦合）；
- **不要跨 widget 目录 import 子组件**：组件应自包含，第三方可整体替换；需要共享的只能是 `src/core/`（纯）或 `src/ui/` 公共件。

## 六、命名与注释

- 全中文注释；文件头写清职责；
- 子组件/`useXxx` 用能自解释的名字；
- 导出的公共类型（props/返回值）加简短 JSDoc。

## 七、清单

- [ ] 单文件 ≤ 520 行（`pnpm lint` 通过）
- [ ] 可测纯逻辑放进 `src/core/` 并补单测
- [ ] 入口 `index.vue` 保持薄（只编排）
- [ ] 子组件用 props 传入，不读全局
- [ ] 未跨 widget 目录 import 子组件
- [ ] 文件头有中文职责注释
